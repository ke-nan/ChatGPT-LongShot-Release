# ChatGPT LongShot

一个仿 Snipaste 交互的单文件、原生 Windows 长截图工具。程序不依赖 .NET、Python 或浏览器扩展。

## 使用

1. 启动后程序自动隐藏到系统托盘。默认截图快捷键是 **Ctrl+Alt+S**；左键单击托盘图标也可截图。
2. 拖动框选 ChatGPT 消息正文；松开鼠标后工具栏立即出现，拖动八个白色控制点仍可调节大小。
3. 无需再次点击，将鼠标放在选区内向下滚动滚轮；选区内部的网页会同步滚动，边框和工具栏始终显示。
   快速滚动会自动拆成小步并逐帧截取；松开滚轮后若网页继续滚动片刻，表示程序正在完成队列中的剩余步骤。
   向上回滚会按实际位移撤销最后截取的区域，实时高度同步减少，不会重复追加相同内容。
4. 工具栏右对齐显示“退出、保存、复制”三个图标。保存时每次都会打开位置选择框：首次默认是 exe 所在目录，之后默认是上一次成功保存的目录。
5. 截图期间随时按 `Esc`、在选区外按鼠标右键，或点击工具栏“退出”图标结束本次截图，托盘程序不会退出；统一操作提示会跟随鼠标并始终限制在选区内显示。

滚动停止后仍可拖动八个控制点调整选区宽度和高度；程序会按最终选区重新裁切所有已缓存的滚动帧，不会清空已经截取的长区域。调整过程使用双缓冲绘制，避免选区内部闪烁。

右键托盘图标 → “快捷键设置...”可以自定义 Ctrl、Shift、Alt、Win 与字母键、F1–F12 或 PrintScreen 的组合。配置保存在 `ChatGPT-ScrollShot.ini`。

中间帧只采用连续滚动内容，并用下一张重叠画面补齐，因此不会重复带入 ChatGPT 的固定控件。最终帧严格采用调整后的完整选区，不再裁掉底部安全区域；建议滚到对话底部、圆形箭头消失后再保存。
